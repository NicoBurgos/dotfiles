# 📈 Mis Inversiones - Dashboard de Portfolio

Una aplicación moderna y responsive para el seguimiento de inversiones en acciones y criptomonedas.

## ✨ Características Principales

### 🎯 **Dashboard Completo**
- **Resumen visual** con métricas clave del portfolio
- **Gráficos interactivos** para visualizar la evolución de inversiones
- **Separación por tipo**: Acciones y Criptomonedas
- **Cálculo automático** de ganancias/pérdidas en USD y porcentaje

### 📊 **Visualizaciones Avanzadas**
- **Gráfico de torta**: Distribución del portfolio
- **Gráfico de barras**: Comparación invertido vs valor actual
- **Gráfico de línea**: Evolución temporal del portfolio
- **Responsive**: Se adapta a móviles y tablets

### 💰 **Gestión de Transacciones**
- **Formulario intuitivo** para agregar nuevas compras
- **Conversión automática** ARS → USD con tasas de cambio reales
- **Historial completo** de todas las transacciones
- **Precio promedio** calculado automáticamente

### 🔄 **Precios en Tiempo Real**
- **Actualización automática** cada 10 minutos
- **APIs integradas**: CoinGecko (crypto) y Alpha Vantage (acciones)
- **Almacenamiento histórico** de precios

## 🛠️ **Tecnologías**

### Frontend
- **Astro 4.0** - Framework web moderno
- **Svelte 4.0** - Componentes reactivos
- **ApexCharts** - Gráficos interactivos
- **CSS Grid/Flexbox** - Diseño responsive

### Backend
- **Go 1.22** - Lenguaje de programación
- **Fiber** - Framework web rápido
- **SQLx** - ORM para PostgreSQL
- **APIs externas** - Precios y tasas de cambio

### Base de Datos
- **PostgreSQL 15** - Base de datos relacional
- **Docker** - Containerización

## 🚀 **Instalación y Uso**

### Prerrequisitos
- Docker y Docker Compose
- Git

### Pasos de instalación

1. **Clonar el repositorio**
```bash
git clone <repository-url>
cd inversiones
```

2. **Configurar variables de entorno**
```bash
# Crear archivo .env en la raíz del proyecto
echo "ALPHA_VANTAGE_KEY=tu_api_key_aqui" > .env
```

3. **Ejecutar con Docker Compose**
```bash
docker-compose up --build
```

4. **Acceder a la aplicación**
- Frontend: http://localhost:3000
- Backend API: http://localhost:8080
- Base de datos: localhost:5432

## 🔧 **Configuración de APIs**

### Alpha Vantage (Acciones)
1. Registrarse en [Alpha Vantage](https://www.alphavantage.co/support/#api-key)
2. Obtener API key gratuita
3. Agregar al archivo `.env`:
```
ALPHA_VANTAGE_KEY=tu_api_key_aqui
```

### CoinGecko (Criptomonedas)
- No requiere API key
- Límite de 50 requests/minuto

## 📊 **Estructura de Base de Datos**

### Tabla `transactions`
- `id`: ID único
- `asset_symbol`: Símbolo del activo (BTC, AAPL, etc.)
- `asset_type`: Tipo (crypto/stock)
- `qty`: Cantidad comprada
- `price_ars`: Precio en pesos argentinos
- `fx_rate_usd`: Tasa de cambio ARS→USD
- `price_usd`: Precio en dólares
- `date`: Fecha de la transacción

### Tabla `prices`
- `id`: ID único
- `asset_symbol`: Símbolo del activo
- `asset_type`: Tipo (crypto/stock)
- `price_usd`: Precio en dólares
- `timestamp`: Fecha y hora del precio
